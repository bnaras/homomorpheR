# Precomputed results for the `cox` vignette

Precomputed results for the `cox` vignette

## Usage

``` r
cox_results
```

## Format

A list with `coef` (estimate and standard-error matrix of the encrypted
single-decrypter [`stats4::mle()`](https://rdrr.io/r/stats4/mle.html)
fit), `loglik` (its log-likelihood), and `counts` (function and gradient
evaluation counts).

## Source

`data-raw/cox_results.R`, from `vignettes/cox.Rmd`.
