# Decrypt the master's protocol result back to a scalar real

Dispatches on the master's class.

## Usage

``` r
master_decrypt(master, ...)
```

## Arguments

- master:

  a [Master](https://bnaras.github.io/homomorpheR/reference/Master.md).

- ...:

  method-specific arguments. Both backends take a single `ciphertext` of
  the appropriate type.

## Value

a single numeric value.
