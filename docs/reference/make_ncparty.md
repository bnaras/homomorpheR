# Construct an [NCParty](https://bnaras.github.io/homomorpheR/reference/NCParty.md)

Construct an
[NCParty](https://bnaras.github.io/homomorpheR/reference/NCParty.md)

## Usage

``` r
make_ncparty(name, number)
```

## Arguments

- name:

  short identifier shown in printed output.

- number:

  which share this NCP receives, `1` or `2`.

## Value

an [NCParty](https://bnaras.github.io/homomorpheR/reference/NCParty.md).
